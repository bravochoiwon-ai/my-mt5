# 마피아 게임 — 오프라인 진행 도우미

오프라인 모임에서 사회자를 돕는 **단일 파일 웹앱**입니다.
서버가 필요 없습니다. `index.html`을 브라우저로 열기만 하면 됩니다.

## 무엇을 해주나

1. **인원·직업 설정** — 인원수와 마피아/의사/경찰/시민 구성을 정합니다.
2. **역할 분배(돌려보기)** — 기기를 한 명씩 돌리며 자기 직업만 몰래 확인합니다.
3. **밤 페이즈** — 마피아 지목 → 의사 보호 → 경찰 조사 순서로 진행을 안내하고 결과를 계산합니다.
4. **낮 페이즈** — 토론 타이머 후 투표로 한 명을 지목해 처형합니다.
5. **승패 판정** — 마피아가 전멸하면 시민 승리, 마피아 수가 시민 이상이 되면 마피아 승리.

## 직업

| 직업 | 진영 | 능력 |
|------|------|------|
| 마피아 | 마피아 | 밤마다 한 명을 지목해 제거 |
| 의사 | 시민 | 밤마다 한 명을 보호(살해 무효) |
| 경찰 | 시민 | 밤마다 한 명의 정체(마피아 여부) 확인 |
| 시민 | 시민 | 능력 없음, 낮 토론·투표 참여 |

## 사용법

브라우저로 `mafia/index.html`을 엽니다. (모바일/PC 모두 가능)
