# 마피아 게임 — 오프라인 진행 도우미

오프라인 모임에서 사회자를 돕는 **단일 파일 웹앱**입니다.
서버가 필요 없습니다. `index.html`을 브라우저로 열기만 하면 됩니다.

## 무엇을 해주나

1. **인원·직업 설정** — 인원수와 마피아/의사/경찰/시민 구성을 정합니다.
2. **역할 분배(돌려보기)** — 기기를 한 명씩 돌리며 자기 직업만 몰래 확인합니다.
3. **밤 페이즈** — 마피아 지목 → 의사 보호 → 경찰 조사 순서로 진행을 안내하고 결과를 계산합니다.
4. **낮 페이즈** — 토론 타이머 후 투표로 한 명을 지목해 처형합니다.
5. **승패 판정** — 마피아가 전멸하면 시민 승리, 마피아 수가 시민 이상이 되면 마피아 승리.

## 진영

- **마피아팀** — 마피아, 청부업자
- **시민팀** — 시민, 의사, 경찰, 정치인, 자경단원
- **교주팀** — 교주 + 포섭된 신도들
- **중립(단독)** — 용병

## 직업

| 직업 | 진영 | 능력 |
|------|------|------|
| 마피아 | 마피아 | 밤마다 한 명을 지목해 제거 |
| 청부업자 | 마피아 | 밤마다 마피아와 별개로 한 명을 추가 제거 |
| 의사 | 시민 | 밤마다 한 명을 보호(그날 밤 공격 무효) |
| 경찰 | 시민 | 밤마다 한 명의 정체(마피아팀 여부) 확인 |
| 정치인 | 시민 | 낮 투표 2표 행사, 투표 처형 1회 면역 |
| 자경단원 | 시민 | 밤에 사살(총알 2발). 무고한 시민팀을 쏘면 본인도 사망 |
| 용병 | 중립 | 의뢰 대상을 끝까지 생존시키면 단독 승리. 대상 사망 시 시민팀 합류 |
| 교주 | 교주 | 밤마다 한 명 포섭. 생존자 전원 신도화 시 승리, 교주 사망 시 패배 |
| 시민 | 시민 | 능력 없음, 낮 토론·투표 참여 |

## 승리 조건

- **시민팀**: 마피아와 교주가 모두 사라지면 승리
- **마피아팀**: 마피아 수가 나머지 생존자 수 이상이 되면 승리
- **교주팀**: 생존자 전원이 교주/신도가 되면 승리 (교주가 죽으면 신도 해제)
- **용병**: 게임 종료 시 본인과 의뢰 대상이 모두 생존해 있으면 단독 승리(팀 승리와 별개)

## 사용법

브라우저로 `mafia/index.html`을 엽니다. (모바일/PC 모두 가능)
