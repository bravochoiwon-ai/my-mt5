# 나의 공간 (my-mt5)

나만을 위한 개인 대시보드 — **나(MBTI·진로·학업 선호·가치관)** + **나만의 도서관(독서 결·서재·신간·추천)**.
외부 라이브러리 없이 순수 HTML/CSS/JS로 만든 **시제품**입니다. 비공개 개인용.

## 열기
`index.html`을 브라우저로 그냥 열면 됩니다. (빌드·서버 불필요)

## 구조
```
index.html        화면 구조 (탭: 나 / 나만의 도서관)
assets/styles.css 디자인
assets/data.js    ★ 샘플 데이터 (프로필·책·신간) — 여기를 내 정보로 교체
assets/charts.js  SVG 레이더 차트
assets/app.js     탭·렌더링·모달·책 추가 로직
```

## 지금 되는 것
- **나**: 프로필 4카드, AI 진로·적성 분석(저장형), 독서 결 7축 레이더 + 누적/평균 막대
- **도서관**: 내 서재(읽음/관심 필터), 책 클릭 → AI 줄거리·추천 별점·책 특성 레이더
- **책 직접 입력**: 추가하면 브라우저(localStorage)에 저장
- **이번 달 신간**: 자리만 마련 (외부 도서 API 연결 예정)
- **추천**: 내 서재 장르·평점 기반 추천 장르/작가
